# Автоматические тесты для сайта https://demoqa.com/

Требуемый SDK:
.NET 9.0

Требуемые пакеты:

* Selenium.WebDriver (4.35.0)
* NUnit (3.13.3)
* NUnit.Analyzers (3.6.1)
* NUnit3TestAdapter (4.4.2)
* Newtonsoft.Json (13.0.3)
* Microsoft.NET.Test.Sdk (17.7.1)
* coverlet.collector (3.2.0)
* NLog (6.0.3)

Запуск тестов

1. Перейти в директорию task3
2. Запустить команду

   ```dotnet test```
